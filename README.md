# FFmpeg corresponding source

Corresponding source for FFmpeg and ffprobe distributed with **fTool Media Cutter**
by futomi.app.

Download the source files from [Releases](https://github.com/futomi-app/ftool-media-cutter-ffmpeg-sources/releases).
Select the release matching the FFmpeg build listed in the app's open-source notices.

Download **both attached source ZIPs** and `SHA256SUMS.txt`. GitHub's automatically
generated **Source code (zip)** and **Source code (tar.gz)** downloads do not contain
the complete corresponding source.

The ZIPs include dependency sources, build scripts and instructions (`BUILD.txt`),
and copyright and license notices.
